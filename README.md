
# Web Server en NodeJS

Realizamos un servidor Web para servir a una web de tipo red social similar a twitter

## ¿Cómo usarlo?

1. Debes clonar el repositorio `git clone https://github.com/SabriFede/node_web_server.git`
2. En la terminal de tu editor de codigo, ejecuta el comando `npm install`
3. Debes armar tu variable de entorno `.env` con la plantilla que dejamos disponible (.env.template). Recomendado PORT: 300 y carpeta 'PUBLIC'.
4. Ya puedes ejecutar el proyecto usando `npm start`
